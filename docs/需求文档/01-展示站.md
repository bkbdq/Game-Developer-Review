# M1 · 展示站

> 模块：访客浏览与转化 ｜ 读者：产品 + 前端
> 关联：M2 评级、M5 数据、M6 匿名
> 状态：已上线，本期改版

---

## 1. 模块职责

- 让访客快速判断：这家公司怎么样、这个项目值不值得去
- 让“看完”自然变成“我也写一条”：全站有一眼可见的入口
- 展示内容服从匿名规则（小样本不露细节、项目可匿名）

---

## 2. 现状（用户看到的样子）

| 页面 | 现在能看到什么 |
| --- | --- |
| 首页 | 项目轮播、精选项目、全部项目列表，可按名称搜索 |
| 公司目录 | 公司卡片、搜索、按综合评分/评价数/最近更新排序 |
| 公司页 | 公司信息（含别名）、旗下项目、开发者评价（只可按具体项目筛选）、评分分布、画像统计 |
| 项目页 | 项目封面、等级、评价列表 |

现状问题：

| 编号 | 问题 | 用户感受 |
| --- | --- | --- |
| 1 | 全站没有“写评价”入口 | 看完想写却找不到地方 |
| 2 | 公司页/公司卡没有等级 | 只有 4.2 分，不如“褒贬不一”直观 |
| 3 | 不填项目的评价混在“全部”里 | 想看“匿名项目”的评价没有入口 |
| 4 | 小样本也显示在职时长和项目名 | 3 人团队的评价能被认出来 |
| 5 | 评分过少时也敢下结论 | 1 条 2 星就显示“差评” |
| 6 | 空状态没有引导 | 新公司页面只有一句“暂无评价” |
| 7 | 公司页展示别名 | 页面杂乱，且别名不是产品要表达的信息 |
| 8 | 没有关于/隐私/联系我们入口 | 用户看不到匿名承诺，也找不到人 |

## 3. 前端展示设计

### 3.1 优化点

| 编号 | 优化 | 描述 | 优先级 |
| --- | --- | --- | --- |
| FE-1 | 全站写评价入口 | 顶栏右侧固定“写评价”；公司页“评价这家公司”；项目页“评价这个项目”；空状态各一处 | P0 |
| FE-2 | 公司级等级 | 公司页顶部显示等级 + 好评率 + 样本数；公司卡显示等级徽标 | P0 |
| FE-3 | 评分过少状态 | 公司/项目评价 <5 条时显示“评分过少”，附“满 5 篇后显示等级” | P0 |
| FE-4 | 小样本隐藏 | 公司评价 <5 条：评价卡不显示在职时长和项目信息，不提供筛选 | P0 |
| FE-5 | 匿名项目筛选 | 公司页评价筛选：全部 / 匿名项目 / 具体项目；匿名项目评价不出现在项目页 | P0 |
| FE-6 | 公司卡信息重排 | 等级 → 公司名 → 项目数/评价数 → 综合分 → 最近更新（不展示别名） | P0 |
| FE-7 | 公司目录排序 | 默认按等级（评分过少置底），保留评价数/最近更新 | P0 |
| FE-8 | 项目页对齐 | 显示等级、好评率、样本数、写评价入口 | P0 |
| FE-9 | 空状态 | 无评价时给“成为第一个评价的人”；搜索无结果给“查看全部” | P0 |
| FE-10 | 首页公司露出 | 项目卡上增加公司名与公司等级，点击进公司页 | P1 |
| FE-11 | 关于/隐私/联系我们 | 页脚增加三个入口 | P1 |
| FE-12 | 移动端 | 375px 无横向滚动；按钮可点区域足够大；等级不只靠颜色 | P1 |

### 3.3 页面设计

#### 首页

- 顶部一句定位：匿名评价游戏公司，帮后来者少踩坑，也帮好团队被看见
- 项目卡：封面、项目名、公司名 + 公司等级、项目等级、评价数
- 精选区标题改为“最近收到好评的项目”，避免榜单感
- 顶栏“写评价”

#### 公司目录

- 卡片：等级徽标、公司名、项目数、评价数、综合分、最近更新
- 不展示别名
- 默认按等级排序，评分过少的卡片灰色标注“样本不足”
- 空状态：“还没有公司数据，去写第一条评价”

#### 公司页

自上而下：

1. 公司名、项目数、评价数
2. **评级区**：等级 + 好评率 + 好评/中评/差评条数 + 样本说明 + “评价这家公司”
3. 分区导航：旗下项目 / 开发者评价 / 评分概况
4. 项目列表（每个项目带等级）
5. 评价列表：筛选为「全部 / 匿名项目 / 具体项目」
6. 侧栏：评分分布、画像统计（5 条以上才显示）

评价卡内容：评分、正文、在职时长（5 条以上才显示）、月份、项目名或“匿名项目”（5 条以上才显示项目信息）。

#### 项目页

- 公司入口、项目名
- 等级 + 样本数 + 好评率 + 写评价按钮
- 评价列表（少于 5 条时隐藏在职时长）
- 不展示任何“匿名项目”的评价

#### 全局

- 顶栏：品牌、项目发现、公司目录、写评价
- 页脚：匿名说明、关于、隐私、联系我们
- 全站不出现“吐槽/牛马/996/爆料”

## 4. 后台数据（展示站依赖什么）

- 公司等级、好评率：来自该公司全部已发布评价的评分（见 M2）
- 项目等级：来自该项目全部已发布评价的评分
- 评价卡字段：评分、正文、在职时长、发布月份、项目名或匿名项目
- 样本数：决定显示等级还是“评分过少”，以及是否显示在职时长/项目信息
- 匿名项目：用户勾选“不公开项目名”后，该评价不关联具体项目
- 公司别名：只用于搜索匹配，不在页面展示

展示站不直接对外暴露：提交时间、回执、审核信息、联系方式。
