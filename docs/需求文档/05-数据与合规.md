## 1. 模块职责

- 用产品语言说清楚：平台有哪些数据、各自什么类型、谁提供、是否公开、留多久
- 划定“公开数据”和“内部数据”的边界，任何新功能都不能越界
- 说明合规底线：不收集什么、真名风险怎么兜、用户怎么删除

## 2. 数据总览

平台的数据分三类：**用户提交的**、**平台维护的**、**系统记录的**。

### 2.1 用户提交

| 数据 | 类型 | 必填 | 是否公开 | 展示位置 |
| --- | --- | --- | --- | --- |
| 公司名（填写值） | 文本 | 是 | 审核归并后公开 | 公司页 |
| 项目名（填写值） | 文本 | 否 | 视情况公开 | 项目页或“匿名项目” |
| 是否不公开项目名 | 勾选 | 否 | — | 决定项目名是否公开 |
| 综合评分 | 数字（1–5 星） | 是 | 公开 | 评价卡、评级统计 |
| 评价正文 | 长文本 | 是 | 公开 | 评价卡 |
| 在职时长 | 选项（1 年以内 / 1–3 年 / 3–5 年 / 5 年以上） | 否 | 公开（小样本隐藏） | 评价卡 |
| 同意声明 | 勾选 | 是 | 不公开 | — |
| 回执编号 | 文本 | 系统生成 | 不公开 | 成功页、删除申请 |

> 没有岗位、没有在职状态、没有城市、没有分项评分。

### 2.2 平台维护（公司/项目目录）

| 数据 | 类型 | 是否公开 | 用途 |
| --- | --- | --- | --- |
| 公司名称 | 文本（真名） | 公开 | 目录、页面标题 |
| 公司别名 | 文本列表 | **不公开**（仅内部） | 搜索匹配、审核归并，避免同一公司被拆成两条 |
| 项目名称 | 文本 | 公开 | 项目页、公司页 |
| 项目状态 | 选项（已上线 / 在研 / 已取消 / 未知） | 公开 | 项目页展示 |
| 公司/项目编号 | 内部编号 | 不公开 | 系统内部关联 |

### 2.3 系统记录（内部）

| 数据 | 类型 | 是否公开 | 保留期 |
| --- | --- | --- | --- |
| 提交时间 | 日期时间 | 不公开 | 随原始提交一起清理 |
| 审核状态 | 选项（待审 / 已通过 / 已拒绝） | 不公开 | 长期（不含正文） |
| 审核记录（谁、何时、通过/拒绝、原因） | 记录 | 不公开 | 长期保留，不含正文 |
| 网络地址的加密摘要 | 文本 | 不公开 | 30 天 |
| 原始提交内容 | 文本 | 不公开 | 待审 90 天；通过后 7 天；拒绝 30 天 |
| 删除/更正申请 | 记录 | 不公开 | 处理完 90 天 |
| 联系我们的消息 | 记录 | 不公开 | 处理完 90 天 |

### 2.4 公开数据的白名单（只允许这些）

一条公开评价只会包含：**评分、正文、在职时长（可选）、发布月份、项目名或“匿名项目”、所属公司**。

绝不出现在公开数据里：姓名、联系方式、身份证、住址、账号、网络地址、设备信息、精确提交时间、审核人、拒绝原因、回执编号。

## 3. 合规

### 3.1 我们主动不收集

- 姓名、手机号、邮箱、身份证号、住址
- 任何账号（微信/GitHub/手机号登录都不做）
- 精确位置、通讯录、相册、设备指纹
- 国内问卷平台、统计工具、邮件服务的任何埋点

### 3.2 真名带来的风险与兜底

公司用真名，评价可能涉及名誉权与商业秘密。兜底措施：

1. **审核红线**：只写事实与感受；禁止未公开项目代号、内部系统名、人身攻击
2. **个人删除通道**：作者凭回执可申请删除/更正，平台定期处理
3. **联系我们**：公司或其他方通过站内表单提出异议，平台判断处理
4. **免责声明**：内容为提交者个人观点，平台只做形式审核，不构成事实认定
5. **保留审核记录**：证明平台尽到了合理注意义务

### 3.3 保留期（对外承诺）

| 数据 | 保留期 |
| --- | --- |
| 已发布评价的原始提交内容 | 通过后 7 天内删除，只保留公开评价 |
| 未通过的提交 | 拒绝后 30 天内删除 |
| 长期未处理的提交 | 90 天后删除 |
| 网络地址的加密摘要 | 30 天后清空 |
| 审核记录 | 长期保留，不含正文 |
| 删除/联系记录 | 处理完 90 天后删除 |

> 对用户只说“最长保留多久”，不说技术细节；承诺必须与实际处理一致，做不到就不写。

### 3.4 数据在哪里

- 公开评价与公司目录：存放在境外代码托管平台的公开仓库，任何人可查看历史
- 待审内容与审核记录：存放在境外云服务的数据库
- 展示站与问卷：境外静态托管
- 全链路不经过国内厂商的服务器、CDN、统计或邮件服务

### 3.5 用户权利

- **知情**：隐私页说明收集什么、为什么、留多久
- **删除/更正**：作者凭回执提交申请，平台定期处理
- **不提供**：因不收集身份信息，平台无法“查询某条评价是谁写的”
