# M6 · 匿名与删除

> 模块：让“匿名”可信，让作者能撤回 ｜ 读者：产品 + 开发
> 关联：M1 展示规则、M3 提交入口、M4 审核台处理
> 状态：部分实现，本期补齐

---

## 1. 模块职责

- 在**展示端**防反向定位：不是“没写名字”就叫匿名
- 给作者一个能用的删除/更正通道；给外界一个“联系我们”
- 把匿名承诺写成用户看得懂、且做得到的话

---

## 2. 真实风险（按可能性排序）

1. **小团队**：3–5 人的团队，一条“3 人团队，千万外包”加上项目名，基本能锁定是谁
2. **组合定位**：项目 + 在职时长 + 具体细节，拼起来就是一个人
3. **时间比对**：精确到日的发布日期，能和 HR 的离职记录对上
4. **内容泄露**：正文里出现姓名、联系方式、内部代号
5. **平台被要求提供信息**：平台不存身份信息，也就无从提供

---

## 3. 现状（用户看到的样子）

| 规则 | 现状 |
| --- | --- |
| 公司评价少于 3 条 | 不显示“画像统计” |
| 评价卡 | **每条都显示岗位和在职时长**（即使公司只有 1 条评价） |
| 时间 | 只显示到月份（已有） |
| 隐私/关于页 | 没有 |
| 删除/更正 | 没有，只有“去提 issue” |
| 联系我们 | 没有 |

> 岗位字段本期会从问卷和展示中移除，但“评价卡在小样本时露在职时长”的问题仍在。

## 4. 前端展示设计

### 4.1 展示保护规则

按公司已发布评价数决定展示多少：

| 评价数 | 等级 | 在职时长 | 项目信息 | 筛选 |
| --- | --- | --- | --- | --- |
| 0 | 暂无评价 | 不显示 | 不显示 | 无 |
| 1–4 | 评分过少 | **不显示** | **不显示** | 不提供 |
| 5–19 | 显示 | 显示 | 显示（具体项目或“匿名项目”） | 显示 |
| ≥20 | 显示 | 显示 | 显示 | 显示 |

项目页同理：该项目评价 <5 条时，评价卡不显示在职时长。

补充：

- 不显示精确提交日期，只到月份
- 不显示“最近提交”时间戳
- 不做在职时长的分布统计（只显示单条评价上的时段）
- 等级用文字 + 颜色，不能只靠颜色区分

### 4.2 新增页面

| 页面 | 内容 | 优先级 |
| --- | --- | --- |
| 关于 | 产品是什么、为什么匿名、怎么审核、公司真名政策、免责声明 | P1 |
| 隐私 | 收集什么、不收集什么、留多久、怎么删除、数据在哪 | P1 |
| 删除/更正 | 凭回执申请删除或更正 | P1 |
| 联系我们 | 站内表单：说明、可选联系方式 | P1 |

### 4.3 删除/更正流程（作者本人）

1. 作者打开“删除/更正”页，填回执编号、选类型、写原因
2. 页面提示“已收到，平台会定期处理”，**不承诺具体时间**
3. 作者凭回执可在同一页查看处理结果：已收到 / 已处理 / 未通过
4. 处理结果：评价从展示站消失，或内容被更正

**只有作者本人能发起**：凭回执即可，不需要提供身份信息。
公司或其他方不能凭回执申请，只能走“联系我们”，避免出现“公司拿到了回执 = 找到了人”的情况。

### 4.4 联系我们

- 入口：关于页 / 隐私页
- 形式：站内表单，填写问题说明，联系方式选填
- 提交后提示“已收到”；平台定期查看，不承诺回复时效
- 不要求提供回执；公司提出异议时请附上具体评价链接或公司页地址

### 4.5 文案要求

- 隐私页写的保留期必须与实际处理一致
- 删除页只说“定期处理”，不写具体时限
- 回执提示：只出现一次，网站不展示、不再提供，请自行保存
- 提交成功页只写“经审核通过后，会在网站显示”，不写拒绝/通知
- 不用“保证绝对匿名”这类无法兑现的表述，改为说明具体做法

---

## 5. 后台数据（处理规则）

### 5.1 删除/更正申请记录

平台需要记录：回执编号、类型（删除/更正）、原因、状态（已收到/已处理/未通过）、提交时间、处理时间。**不要求填写联系方式**。

### 5.2 处理动作

- 删除：把该评价从公开数据移除，展示端下次更新后消失
- 更正：修改公开评价内容（保留修订记录）
- 两种操作都要留审核记录（谁、何时、做了什么）

### 5.3 联系我们消息

- 记录：内容、可选联系方式、状态、时间
- 处理完 90 天后删除
- 若用户留了联系方式，单独保存，30 天内删除

### 5.4 匿名相关的内部约束

- 不记录可还原的身份信息
- 提交时间、网络地址摘要只用于防刷，按保留期清理
- 审核记录不含评价正文

- [x] 提交删除后，审核台能看到并处理；处理后回执显示“已处理”
- [x] 公司通过“联系我们”提出异议，可在审核台看到
- [x] 全站没有“绝对匿名”“100% 安全”这类承诺
